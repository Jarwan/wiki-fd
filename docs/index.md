# Wiki FD

**Wiki FD** is a demo knowledge base built with [Zensical](https://zensical.org). It exists to prove out three
pieces of tooling before real content gets written into it: LaTeX formulas, interactive Plotly charts, and
syntax-highlighted code blocks.

## Summary

This home page is the entry point into three example articles. Each one is standard *Lorem Ipsum* filler text,
arranged the way a real wiki article would be: a short summary, a body, a worked example of one supported
integration, links to related articles, and a list of sources.
